添加服务器
通过 Unraid 官方 GraphQL API 读写（需 ADMIN 角色密钥）。
支持填写 IP、主机名或完整 GraphQL 地址；未填 /graphql 时会自动补全。
获取方式：Unraid WebGUI → 设置 → 管理访问 → API Keys 新建一个 ADMIN 角色的密钥； 或命令行 unraid-api apikey --create --name widget --roles ADMIN --json。
使用 DSM 账号密码登录（非 API Key）。若账号已开启双重验证，登录时可能要求填写动态验证码； 请先在 DSM 控制面板 → 安全性 → 账户 中确认该账号允许登录。
可留空：此时请把 user@realm!tokenid=secret 整串填到上面的 API Token 框。 若分开填，则此处填 user@realm!tokenid，上面只填 secret。
